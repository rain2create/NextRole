# 岗位搜索试用

运行 `npm run dev` 后打开本机工作台 `/app`。

1. 在“目标岗位”填写 `Credit Risk Analyst` 或 `信贷策略`，按需填写地点。保留“LinkedIn 公开职位”，点击“搜索岗位”。这个来源不需要简历或模型密钥，但本机必须能访问 LinkedIn。
2. 如已配置千问按量应用密钥 `QWEN_API_KEY`，可以上传简历，留空目标岗位，点击“推荐方向”。确认一个或多个建议方向后再搜索。推荐不会发起投递。
3. 可在 `.env.local` 设置 `QWEN_WEB_SEARCH=true` 并重启，启用企业招聘页发现。该来源先搜索候选链接，再用 Greenhouse、Lever、Ashby 公共接口核验；单一来源失败会单独提示。
4. 已有具体职位时，可在“导入岗位”粘贴 LinkedIn 或企业招聘详情链接。无需复制正文。以往保存的数据不会因移除 BOSS 导入而删除。

无密钥试用：仅勾选「Stripe 职位板（Greenhouse）」，目标岗位填 `Credit Risk Analyst`，地点填 `Singapore`。此来源只在 Stripe 当前公开职位中匹配，不代表全网结果；岗位会随招聘状态变化。

列表支持条件筛选、匹配和可撤销的反馈。LinkedIn 列表通常不含完整描述，可点选岗位查看详情再分析。招聘平台拒绝访问时请稍后再试。

## 中文平台搜索

在项目根目录的 `.env.local` 中配置 `APISH_KEY` 并重启服务。打开 `/app`，填写「信贷策略」和「上海」，仅勾选「智联招聘」，点击「搜索岗位」。无需上传简历。

智联招聘搜索通过 API.SH 提供，默认关闭。每个方向只请求第一页，不自动重试。请求包含岗位词、可选城市及鉴权，不向 API.SH 发送简历。请在使用前核对服务商的条款和额度。
